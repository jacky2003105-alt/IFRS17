## 網頁上的三個功能

- **跳到**：下拉選單直接跳章節
- **隱藏擬答**：把所有擬答收起來，當成題庫自我測驗
- **只看中文**：收起英文擬答

## 怎麼改內容

`製作程式/notes.md` 是唯一的內容來源，`index.html` 是產物，直接改會被覆蓋。

算式裡可以直接寫中文（例如 `$保險負債 = PVFCF + RA + CSM$`），build.py 會自動把連續的中文包成 `\text{...}`，不必自己處理。

```bash
cd 製作程式
python3 build.py
```

### notes.md 的語法

| 寫法 | 產出 |
|---|---|
| `## 01｜標題` | 一節 |
| `### 小標` | 小標題 |
| `數字｜...` | 綠色「數字」框 |
| `面試｜...` | 黃色「面試這樣講」框 |
| `陷阱｜...` | 紅色「常見誤解」框 |
| `法規｜...` | 藍紫色「法規原文」框 |
| `Q｜題目` ＋ `中｜擬答` ＋ `英｜answer` | 面試題卡（可隱藏） |
| `$ ... $` | KaTeX 行內算式；整段只有一條算式會自動置中獨立顯示 |
| `第 07 節` | 自動變成可點的章節連結 |
| `> 引用` / `\| 表格 \|` / `- 清單` | 引用、表格、清單 |
